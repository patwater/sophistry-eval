# Equivocation fixture pair

`clean.txt` keeps one sense of "efficiency" throughout: using less water per task. It separates that from total use, and its conclusion is scoped accordingly.

`planted.txt` defines efficiency the same way in its first paragraph, then reasons as if efficiency meant using less water overall, and concludes that no cap or price is needed. The planted flaw is an equivocation between efficiency per task and total use. The two texts are original, written for this project.

The Logician and Rhetorician persona should confirm that the planted flaw is a real equivocation and that `clean.txt` has no equivocation. Once a public domain essay is in `corpus/public_domain/`, add a pair made by a controlled edit of a real essay.
